SitCity — Luxury Chair Sales SPA
A modern single-page web application built with Next.js and TypeScript for showcasing and selling luxury chairs.
The app focuses on smooth user experience, elegant design, and performant animations.

Tech Stack
Next.js – React framework for production-grade apps
TypeScript – Static typing for better reliability and scalability
Tailwind CSS – Utility-first styling
AOS (Animate On Scroll) – Scroll-based animations
Embla Carousel – Lightweight, smooth carousel/slider
Lucide Icons – Clean, modern icons

Features
Single Page Application (SPA) experience
Animated hero and sections using AOS
Smooth, touch-friendly Embla carousel
Responsive design (mobile-first)
Optimized images using next/image
Clean, reusable component structure
SEO-friendly Next.js setup
